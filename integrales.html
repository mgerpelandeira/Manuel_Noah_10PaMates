Integrales

¿Qué es una integral?

La integral es uno de los conceptos fundamentales del cálculo. Se puede entender como el proceso inverso de la derivada, y se utiliza principalmente para calcular áreas, acumulaciones y cantidades totales.

Mientras que la derivada mide el cambio de una función, la integral mide cuánto se acumula ese cambio.

Por ejemplo, si conocemos la velocidad de un objeto, podemos usar integrales para calcular la distancia recorrida.

---

Interpretación gráfica

Gráficamente, una integral representa el área bajo la curva de una función en un intervalo determinado.

Si la función está por encima del eje X, el área es positiva; si está por debajo, el área se considera negativa.

---

Tipos de integrales

  • Integral indefinida: no tiene límites y representa una familia de funciones.
  • Integral definida: tiene límites y da un valor numérico (área).
---

Cómo calcular integrales

Regla básica de potencias

∫ xⁿ dx = xⁿ⁺¹ / (n+1) + C

La constante C aparece porque existen infinitas funciones cuya derivada es la misma.

---

Otras reglas importantes

  • ∫ k dx = kx + C
  • ∫ (f + g) dx = ∫f dx + ∫g dx
  • Factor constante: k∫f dx
---

Ejemplos básicos

∫ x dx = x² / 2 + C

∫ x² dx = x³ / 3 + C

∫ 5 dx = 5x + C

---

Ejemplo paso a paso

∫ 3x² dx

Paso 1: aplicar regla → 3 · (x³ / 3)

Paso 2: simplificar → x³

Resultado final: x³ + C

---

Integral definida (ejemplo)

∫₀² x dx

Paso 1: calcular primitiva → x²/2

Paso 2: evaluar → (2²/2) - (0²/2)

Resultado: 2

---

Aplicaciones de las integrales

  • Cálculo de áreas
  • Volúmenes de sólidos
  • Física (movimiento, trabajo)
  • Economía (costes acumulados)
---

Errores comunes

  • Olvidar sumar +C
  • No dividir por el nuevo exponente
  • Confundir integral con derivada
