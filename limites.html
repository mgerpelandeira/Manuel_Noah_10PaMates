Límites

Un límite es el valor al que se acerca una función cuando x se aproxima a un número.

Cómo se calculan

Se sustituye directamente el valor. Si hay problemas (0/0), se simplifica.

Ejemplos

lim (x→2) (x+3) = 5

lim (x→0) (x²) = 0

Práctica

¿Cuánto vale lim (x→3) (x+2)?
