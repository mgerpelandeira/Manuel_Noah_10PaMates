Límites

Un límite es el valor al que se acerca una función cuando la variable independiente (normalmente x) se aproxima a un número concreto. Aunque la función no esté definida en ese punto, el límite puede existir.

Los límites son fundamentales en cálculo porque permiten estudiar el comportamiento de las funciones en puntos específicos, especialmente cuando hay discontinuidades o cambios bruscos.

Cómo se calculan

Para calcular un límite, normalmente se sustituye directamente el valor en la función. Si el resultado es un número normal, ese es el límite.

Sin embargo, a veces aparecen indeterminaciones como:

  • 0 / 0
  • ∞ / ∞

En estos casos se utilizan técnicas como:

  • Factorizar la expresión
  • Simplificar términos
  • Racionalizar

Tipos de límites

1. Límite finito: da un número concreto.

2. Límite infinito: crece sin límite.

3. Límite lateral: cuando se estudia por la izquierda o derecha.

Ejemplos resueltos

lim (x→2) (x + 3) = 5

lim (x→0) (x²) = 0

lim (x→1) (2x + 1) = 3

Ejemplo con indeterminación

lim (x→1) (x² - 1) / (x - 1)

Paso 1: factorizar → (x-1)(x+1) / (x-1) Paso 2: simplificar → x+1 Paso 3: sustituir → 2
